# Contributing

Thanks for your interest in contributing to muffy86's projects.

## How to contribute

1. **Find an issue** labeled `good first issue` or `help wanted`
2. **Fork the repo** and create a feature branch
3. **Write tests** for new functionality
4. **Run the test suite** before submitting
5. **Open a PR** using the PR template

## Commit conventions

Use [Conventional Commits](https://www.conventionalcommits.org/):
- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation only
- `chore:` maintenance (deps, configs, etc.)
- `security:` security fix
- `ci:` CI/workflow changes

Example: `feat(agent): add memory persistence for cross-session context`

## Code style

- Python: PEP 8, 100 char lines, 90% coverage on new code
- TypeScript: ESLint + Prettier defaults
- Shell: shellcheck clean
- Markdown: Prettier
